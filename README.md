# LADDER DOWN

## About the Game

LADDER DOWN is a co-op firefighting game for PC, focused on chaotic teamwork, physics-based comedy, reactive fires, and ridiculous rescue missions.

Players fight fires, rescue people, save questionable valuables, and deal with unpredictable situations caused by fire, smoke, physics, and their teammates.

## Project Status

**Current Phase:** Pre-production  
**Game Engine:** To be decided  
**Platform:** PC — Steam  
**Team Size:** 2–5 people

## Core Gameplay Pillars

- Reactive fire and smoke
- Cooperative firefighting
- Rescue missions and difficult choices
- Physics-driven chaos
- Progression and consequences
